## Projetos em Destaque

### 1. **[PostKabum](https://github.com/JoaoBarreto13/postkabum)**
Um sistema inovador de gestão de demandas que combina a simplicidade dos Post-its com a eficiência do Kanban.

- **Tech Stack:** TypeScript, React, Node.js
- **Destaques:**
  - Interface visual e intuitiva
  - Sistema de priorização de tarefas
  - Relatórios de desempenho
  - Design responsivo

---

### 2. **[CFD - Ceifadora Convocatórias](https://github.com/JoaoBarreto13/CFD)**
Plataforma para organização de convocações, controle de presença e compartilhamento de links públicos de confirmação.

- **Tech Stack:** TypeScript, React, Node.js, PostgreSQL
- **Funcionalidades:**
  - Gestão de participantes
  - Controle inteligente de presença
  - Links públicos de confirmação
  - Design mobile-first

---

### 3. **[OLX Consulta Bot](https://github.com/JoaoBarreto13/Olx-consulta-bot)**
Bot inteligente que monitora anúncios da OLX automaticamente e envia notificações sobre novos produtos e variações de preço.

- **Tech Stack:** Python, Web Scraping, Telegram/WhatsApp API
- **Funcionalidades:**
  - Monitoramento automático de produtos
  - Notificações via Telegram ou WhatsApp
  - Rastreamento de variações de preço
  - Busca inteligente e filtragem de anúncios
  - Alertas em tempo real
